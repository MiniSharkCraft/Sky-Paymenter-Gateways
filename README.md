# Sky Paymenter Gateways

Paymenter payment gateway extensions developed by Sky Hosting.

- **SkySePay**: standalone VND bank transfer extension for Paymenter v1.5.9. See [`extensions/Gateways/SkySePay/README.md`](extensions/Gateways/SkySePay/README.md).
- **PhonePe**: retained from the upstream [PhonePe-Paymenter](https://github.com/VaibhavSys/PhonePe-Paymenter) repository as an architectural reference. Its original copyright and MIT license are preserved. It is not used as SePay payment logic.
